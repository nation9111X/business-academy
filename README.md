# Бизнес как система

Интерактивная программа обучения бизнесу уровня MBA для предпринимателя — на русском языке.
Экономика, клиенты и продукт, маркетинг и продажи, юнит-экономика, финансы, право и налоги в России,
команда и операции, стратегия, инвестиции, оценка компаний и выход.

Сайт статический: без сервера, без сборки и без регистрации. Прогресс хранится в браузере.

## Что внутри

- **Последовательная программа:** 6 частей, 25 модулей, 114 уроков (~92 тыс. слов). Внутри модуля по порядку
  идут уроки, истории компаний, симуляторы, сценарии решений и повторение.
- **Практика:** 47 симуляторов и тренажёров, 22 истории компаний с вопросом «что бы сделал ты»,
  7 ветвящихся сценариев решений, мини-игра «Стартап за 24 месяца».
- **Проверка знаний:** 473 вопроса в тестах, 55 задач на расчёт, разминка дня, итоговый экзамен с сертификатом.
- **Справочники:** словарь на 448 терминов с карточками для интервального повторения, 52 формулы,
  библиотека книг, курсов, видео и статей.
- **Рабочая тетрадь:** ответы на практические задания складываются в итоговый бизнес-план.
- **Геймификация:** опыт, стадии от «Идеи» до «Голубой фишки», серия дней, награды.
- **Оформление:** три палитры (сапфир, графит, сепия), светлая и тёмная тема, размер текста, адаптация под телефон.

## Как открыть

**Онлайн через GitHub Pages:**

1. Загрузи содержимое папки в репозиторий (в корень, чтобы `index.html` лежал рядом с README).
2. Открой **Settings → Pages**.
3. В блоке **Build and deployment** выбери **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту-две сайт появится по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

**На своём компьютере:**

- Двойной клик по `index.html` — сайт откроется в браузере.
- Или запусти локальный сервер (нужен Node.js 18+): `node tools/serve.mjs` и открой http://localhost:5200

Для шрифтов и портретов людей нужен интернет. Без сети сайт работает со стандартными шрифтами
и монограммами вместо портретов.

## Устройство

```
index.html        точка входа
css/style.css     оформление
js/               движок: маршруты, интерфейс, графики, симуляторы, эффекты
content/          тексты: уроки, теория, словарь, истории, сценарии, программа
tools/serve.mjs   мини-сервер для локального просмотра
```

- Порядок шагов программы — `content/program.js`.
- Уроки регистрируются через `BA.lesson({...})`, дополнительная теория — через `BA.deepen(id, [...])`.
- Прогресс хранится в `localStorage` браузера; перенести его на другое устройство можно кодом из раздела «Профиль».

## Важно

Налоговые и правовые цифры актуальны на 2026 год. Курс — образовательный материал, а не юридическая,
налоговая или инвестиционная консультация.
